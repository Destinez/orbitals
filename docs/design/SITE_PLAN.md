# Resonance Site Plan

The site is a scroll-driven recovered survey log. The object and the record alternate emphasis: most records keep the plot on the right and the observation on the left; selected records reverse those positions so the survey feels like an instrument being read from changing bearings.

The central observation remains unchanged: object 0417 holds a clean 3:2 resonance. The survey has logged 3,232 passes. The predicted driver is absent below five sigma.

The mission protocol is a short interactive coda after the archive. Visitors first read the evidence, then move through four public signal prompts. The console waits for the visitor to return to the tab, simulates a ten-second instrument synchronization without claiming server verification, and unlocks the next coordinate. The final observer record collects an X username, receiving wallet, and public quote-post URL for manual review.
